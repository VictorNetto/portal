# Templates

Many reports start with the same texts: an executive summary with the same structure, an introduction that explains the team's methodology, sections that repeat from one operation to the next. A **template** keeps those texts, so that a new report doesn't start from nothing.

A template has the same three text parts as a report: the Executive Summary, the Introduction and the Additional Sections. Templates live in the menu under **Reports ➝ Templates**, and are offered when you create a report.

It is worth knowing from the start how a template relates to reports: the report **copies** the template's text when it is created. Changing the template later doesn't change the reports that already exist, and editing a report never changes the template it came from.

<!-- page: tpl-salvar -->
# Saving a template

The most natural way to create a template is from a report that turned out well. On the report's page, **Save as Template** keeps the current Executive Summary, Introduction and Additional Sections as a new template of yours. The operation's data and the vulnerabilities don't go into the template: it only keeps the texts.

A newly created template is **Private**. Only you see and use it, and you can edit or delete it whenever you like.

# Sharing with the team

A private template serves only you. For the whole team to use it, it has to be **shared**, and sharing goes through an administrator, so that the team's list of templates doesn't fill up with drafts.

To ask, use **Request sharing**. The template becomes **Awaiting approval**, and from then on you can no longer change it, because the administrator has to approve exactly what will be shared. If you change your mind, **Cancel request** returns it to private.

The administrator then reads the template and decides. If they **approve** it, the template becomes **Shared** and available to everyone. If they **reject** it, it goes back to private, and you can adjust it and ask again.

A shared template belongs to the team, so only administrators change it. If you want to change something in it, create a new template from a report. An administrator can also **unshare** a template, which becomes **Unavailable** (nobody uses it, not even the author), and **share it again** later.
